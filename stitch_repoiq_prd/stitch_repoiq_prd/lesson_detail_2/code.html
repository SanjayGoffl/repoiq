Understanding the Reconciliation Loop

The Fiber architecture allows React to split the rendering work into small chunks and spread it out over multiple frames. This is essentially what enables Concurrent Mode.

Fig 1.2: The Work Loop Interruption Pattern

zoom_in

1 Work Progress

When React starts working on a tree, it creates a workInProgress tree that mirrors the current state. Each node in this tree is a "Fiber" — a plain JavaScript object that contains information about a component, its input, and its output.

Insight

"Fibers are like stack frames for the web. They hold context, state, and child references in a way that can be paused and resumed by the browser's main thread."

2 Effect Tags

As the reconciliation proceeds, React marks fibers with Effect Tags (like Placement, Update, or Deletion). These are processed later during the "commit" phase.
